# Question Structure

- description: `A question is formed in several parts`

## Parts

- description_field: `A description of the question. Not shown to students.`
- use_rights:
  - desc: `Rights granted to other people (you always have full rights)`
  - options: `Private`, `Use, no modification`, `Use, allow modification`
- libraries: `The question libraries you wish to include this question in`
- question_type: `The type of question`
- common_control: `General definitions needed for both display and scoring`
- question_control: `Definitions only needed for question display`
- question_text: `The actual question display. HTML-based but can include variables. A blank line is automatically interpreted as a paragraph break. Use of < and > signs are usually handled ok, but HTML < and > are recommended.`
- answer: `Code defining the answer`
