# Core Libraries

Core libraries are **always available** in every IMathAS question — no `loadlibrary()` call needed. They provide the fundamental building blocks for randomization, display, math, and string handling.

Back to [index.md](index.md)

## Core Randomizers

| Field | Value |
|-------|-------|
| **Section** | `randomizers` |
| **loadlibrary needed** | No |
| **Description** | Random number generators, array shuffling, random selection |
| **Help URL** | https://www.myopenmath.com/help.php?section=randomizers |
| **Macro reference** | [../macros/randomizers.md](../macros/randomizers.md) |

Key functions: `rand()`, `nonzerorand()`, `diffrands()`, `randfrom()`, `shuffle()`
