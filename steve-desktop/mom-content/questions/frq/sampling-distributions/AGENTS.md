## Conventions

- Layout C (informal): `//question text` marker, `///` separator, `$questiontext`/`$rubricanswerbutton` pattern.
- Shared `$css_block` from `mom-style-guide` (matches `inference-for-proportions/q1`).
- `editornopaste` display format to discourage copy-paste.
- Random scenario picker via `rand(0, count - 1)` against parallel arrays.
- Step-by-step rubric with checklist (student-facing) and ideal targets (instructor-facing).
- Model narrative response always renders the full ideal answer for instructor reference.
